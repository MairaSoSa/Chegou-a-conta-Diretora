3) Se você estiver tentando puxar no FRONT (browser), o bloqueio pode ser CORS

O site é www.fnde.gov.br e seu app é outro domínio → o fetch() do navegador pode ser bloqueado.

✅ Solução prática: crie um endpoint proxy no seu backend (Next.js API route, Express, FastAPI) e faça o backend chamar o FNDE.

Exemplo (Node/Express) — retorna o HTML cru:

import express from "express";

const app = express();

app.get("/proxy/pddeinfo/escola/consultar", async (req, res) => {
  const url = new URL("https://www.fnde.gov.br/pddeinfo/pddeinfo/escola/consultar");
  for (const [k, v] of Object.entries(req.query)) {
    url.searchParams.set(k, String(v));
  }

  const r = await fetch(url, {
    headers: {
      "accept": "text/html,*/*",
      "user-agent": "Mozilla/5.0",
    },
  });

  const html = await r.text();
  res.setHeader("content-type", "text/html; charset=utf-8");
  res.status(r.status).send(html);
});

app.listen(3001);

4) “Tá vindo HTML: como eu extraio os dados?”

Você tem duas opções:

Opção A) Extrair com cheerio (Node)
import * as cheerio from "cheerio";

function extrairTabela(html) {
  const $ = cheerio.load(html);
  const rows = [];

  $("table tr").each((_, tr) => {
    const cols = $(tr).find("th,td").map((_, td) => $(td).text().trim()).get();
    if (cols.length) rows.push(cols);
  });

  return rows;
}
