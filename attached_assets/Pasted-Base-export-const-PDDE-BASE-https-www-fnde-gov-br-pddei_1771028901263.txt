Exemplo de uso (Node / Fetch)
const BASE = "https://www.fnde.gov.br/pddeinfo";

async function consultarEscola({ ano, uf, municipio }) {
  const params = new URLSearchParams({
    ano,
    sg_uf: uf,
    co_municipio_fnde: municipio,
    consultar: "Consultar"
  });

  const res = await fetch(`${BASE}/pddeinfo/escola/consultar?${params}`, {
    headers: {
      "User-Agent": "Mozilla/5.0",
      "Accept": "text/html,application/json",
      "Referer": "https://www.fnde.gov.br/pddeinfo/"
    }
  });

  const text = await res.text(); // muitas vezes vem HTML
  return text;
}

Boas práticas (pra não quebrar)

Headers básicos: User-Agent, Accept, Referer.

Rate limit: 1–2s entre requisições.

Cache local por ano+inep ou ano+município.

Parser duplo: trate JSON e HTML (cheerio/BeautifulSoup).

Excel: quando existir rota /excel/..., prefira — já vem estruturado.
